# 临时邮箱接码（Chrome 扩展）

通用临时邮箱接码助手。聚合多家免费临时邮箱服务，自由选择域名，**自动实时监测来信**，完整显示邮件原文并智能提取验证码候选，邮箱与验证码一键复制。注册各类网站、跑测试、收一次性验证码都能用。

## 为什么做这个

很多临时邮箱网站要么广告满天飞、要么不能选域名、要么验证码识别只认死板的 6 位数字。这个扩展的取舍：

- **多服务聚合**：一家抽风就换另一家，域名池更大，不容易被目标网站拉黑。
- **完整显示邮件全文**：不同网站验证码格式千差万别（纯数字、字母数字混合、各种长度，甚至是验证链接），所以**直接把邮件正文完整呈现**，再在上方给出「快捷复制候选」，绝不因为格式特殊而漏掉。
- **实时监测**：生成邮箱后自动轮询，收到新码弹桌面通知。

## 支持的服务（均经实测）

| 服务 | 选域名 | 选用户名 | 实测结果 |
| :--- | :--- | :--- | :--- |
| **Mail.tm** | ✓（API 实时返回） | ✓ | ✓ 跑通 |
| **Mail.gw** | ✓ | ✓ | mail.tm 镜像，作容错备用 |
| **Guerrilla Mail** | 服务分配 | ✓ | ✓ 跑通（实测已收到邮件） |
| **TempMail.lol** | 随机分配 | ✗ | ✓ 跑通 |
| **TempMail.plus** | ✓（8 个域名） | ✓ | ✓ 跑通 |

> 实测中 1secmail（已返回 403 停服）、Dropmail（网络超时）暂不可用，已不纳入。验证码多格式提取测试 **5/5 通过**，邮件解析端到端测试 **6/6 通过**（纯数字 / 字母数字混合 / 各长度，正则提不到时由全文兜底）。
>
> 说明：Guerrilla 与 TempMail.lol 的域名由服务端自动分配（实测 Guerrilla 无法通过 API 切换域名），其余服务可自由选域名。

## 功能特性

- 服务 + 域名两级下拉自由选择，支持自定义用户名（留空随机）
- 一键生成邮箱并自动开始监测，邮箱地址一键复制
- 验证码大屏展示 + 多候选 chips，逐个一键复制
- 收件箱列表：发件人 / 主题 / 时间 / 验证码徽章，点开看**完整邮件原文**，可复制全文
- 收到新验证码弹桌面通知（即使没开着弹窗）
- 顶部状态徽章可点击暂停 / 恢复监测，右上角关闭按钮一键收起弹窗
- 深色玻璃拟态 UI，状态完整（空态 / 加载 / 错误 / 监测中脉冲）

## 安装（加载未打包扩展）

### macOS

1. Chrome 地址栏输入 `chrome://extensions/` 回车
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹 `临时邮箱接码`
4. 工具栏出现信封图标，点击即用

> Edge：地址栏 `edge://extensions/`，开「开发人员模式」→「加载解压缩的扩展」，步骤相同。

### Windows

同上，文件夹路径形如 `D:\下载\阿里云自动注册工具\临时邮箱接码`。

## 使用方法

1. 点工具栏的信封图标打开弹窗
2. 选择**邮箱服务**与**域名**（可填用户名，留空随机）
3. 点「生成邮箱并开始接码」——邮箱生成后自动进入监测
4. 点邮箱旁「复制」，把地址填到目标网站
5. 验证码到达后：顶部**最新验证码**自动显示并可一键复制；下方收件箱可展开看**完整邮件原文**
6. 想换地址点「↻ 换邮箱」；想手动拉取点「立即查收」；可用底部开关暂停 / 恢复自动监测

## 工作原理

```
popup（UI/交互） ──消息──▶ background（service worker）
                              │
                              ├─ 多服务适配层：统一 listDomains / create / inbox
                              ├─ 收件：HTML→纯文本全文 + 多格式验证码候选提取
                              ├─ 轮询：弹窗开启时 3 秒/次；关闭时 chrome.alarms 兜底
                              └─ 新码桌面通知 + chrome.storage 状态持久化
```

- service worker 拥有 `host_permissions`，`fetch` 各家接口不受 CORS 限制，网络请求统一在后台发起。
- 各服务 API 差异大（mail.tm 需建账户取 token、Guerrilla 走 session、TempMail.plus 自选地址），由适配层抹平为统一的 `{id, from, subject, date, text, codes}` 结构。

## 注意事项

- 临时邮箱有时效，邮件通常 1 小时左右自动销毁；请及时复制验证码。
- 某些目标网站会屏蔽部分临时邮箱域名；遇到收不到时，**换一个服务或域名**再试。
- 公共临时邮箱服务可能临时波动（限流/维护），扩展已做多服务容错，但仍需网络可达。
- 能否真正收到某网站的验证码，取决于该网站是否向你所选域名投递；扩展只负责「拿到信就解析展示」。
- 本工具仅供学习研究与授权测试使用，请遵守目标网站服务条款。

## 重新加载

改动代码后，在 `chrome://extensions/` 点本扩展的「刷新」↻，再重新打开弹窗即可生效。
